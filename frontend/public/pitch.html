🌸 SHAKTI — Safe & Flexible Work Discovery for Rural Women

Panel-3 • 27 Nov 2026 • VRAJHNA Technologies, Alwar • Est. cost ₹22,00,000 (challenge estimate — not approved budget) • Prototype demo

1. Problem (60 sec)

Over 75% of working rural women are in unpaid/low-productivity agri labour. Work exists nearby — but women can't find it, reach it, trust it, or balance it with childcare + mobility + literacy barriers.

Barriers: can't read job portals • no nearby info • can't travel far • childcare burden • no skills info • fear of fraud (advance fee, OTP, fake home-work).

2. Solution — one woman's journey (demo backbone)

  1. She opens SHAKTI — no resume, Hindi-first, big buttons.
  2. Taps काम ढूंढें → verified jobs within 2/5/10/20 km.
  3. Selects घर से काम → verified listing.
  4. Presses 🔊 सुनें → listens (voice-first).
  5. Applies in 3 questions → status shown.
  6. Opens free lesson → certificate.
  7. Finds Anganwadi (demo) → childcare.
  8. Admin shows verification + moderation + analytics.

Live: open SHAKTI → Jobs → Home-work → Listen → Apply → Skills → Anganwadi → Admin

4. Safety — the differentiator

SHAKTI Safe Work Framework: employer types (Govt / Registered / NGO / SHG / FPO / Cooperative / verified-local) → ID + contact + address check → approve / reject / suspend → re-verification.

Auto-flags: advance fee, registration fee, OTP/Aadhaar/bank ask, too-good pay, unverified home-work, suspicious links. Demo: blocked scam listing j16 kept visible for learning.

Never promises “100% safe” — shows verification + evidence. Report → 48h review → suspend. Helplines 181 / 1090 / 1930 / 112.

7. Honest limits (builds trust)

  • Anganwadi data = demo until WCD dataset integrated.
  • Dialect STT = Hindi + assisted audio now; full dialect STT only after testing.
  • Verification ≠ guarantee — evidence + reporting + re-checks.
  • AI help = optional Meta key; without key, verified local KB (no hallucinated jobs).
  • Privacy: phone-masked public endpoints, no sensitive data in analytics.

8. Ask

We seek pilot approval + dataset access (WCD Anganwadi, SHG/employer registries, SSO/Sewadwaar) + field partners (SHGs, CSCs).

Success metrics: verified applications → interviews → placements; course completions; childcare searches; report resolution <48h; share of home-based/flexible placements.

Closing (say): “Opportunities often exist nearby — women can't safely access them. SHAKTI is accessible opportunity, safety, dignity, and economic participation — starting with a validated pilot.”
